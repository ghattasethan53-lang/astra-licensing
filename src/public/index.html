Astra

A client-side Minecraft mod with block highlighting and the AstraTone navigation engine. Activation happens in the game — one key, one device, no Minecraft server involved.

How to activate Manage keys

Activating Astra

Activation is done inside Minecraft, not on this site. The client claims your key, binds it to that device, and stores a signed credential — so it only ever asks once.

  1. 1
    Launch MinecraftStart the game with Astra installed. The activation screen appears the first time you open the mod.
  2. 2
    Enter your keyType the key you were issued. Every key begins with AST-.
  3. 3
    Astra unlocksHighlighting and AstraTone become available, and the screen never returns on that device.

About your key

Keys look like this:

AST-AuysWUdh1-3421-GHEd

One device per key

A key is claimed by the first device that activates it. Copying the activation file to another computer will not work.

Works offline

After activation the client checks its stored credential locally, so no internet connection is needed to play.

New computer?

Ask for a device reset and your existing key becomes claimable again on the new machine.

Server independence

Astra is entirely client-side. Nothing is installed on a Minecraft server, and your activation belongs to the Astra client — play single-player, join any multiplayer server, switch servers or use LAN worlds without reactivating.
