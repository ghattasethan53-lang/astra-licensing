Astra

A client-side Minecraft mod with block highlighting and the AstraTone navigation engine. Activation is handled here — one key, one device, no Minecraft server involvement.

How to activate Manage keys

Activating Astra

Activation happens inside Minecraft, not on this site. The client claims your key and binds it to that device, then stores a signed credential so it never asks again.

1

Launch MinecraftStart the game with Astra installed. The activation screen appears automatically the first time.

2

Enter your keyType the key you were issued. It begins with AST-.

3

Astra unlocksHighlighting and AstraTone become available, and the screen never returns on that device.

About your key

Keys look like this:

AST-AuysWUdh1-3421-GHEd

◆

One device per keyA key is claimed by the first device that activates it. Copying the activation file to another computer will not work.

◆

Works offlineAfter activation the client checks its stored credential locally, so no internet connection is needed to play.

◆

New computer?Ask for a device reset and your existing key becomes claimable again.

Server independence

Astra is entirely client-side. Nothing is installed on a Minecraft server, and the activation belongs to your Astra client — you can play single-player, join any multiplayer server, switch servers or use LAN worlds without reactivating.
